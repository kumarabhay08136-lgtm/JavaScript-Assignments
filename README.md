# JavaScript Assignments & Capstone Project

## About This Project

This repository contains six JavaScript assignments and one capstone project. I created these projects to practice JavaScript and understand how it works in real examples.

The assignments cover basic concepts like variables, conditions, loops, functions, and arrays. The capstone project is a Product Inventory Dashboard where I used HTML, CSS, and JavaScript to manage products.

## Assignments

### Assignment 1: Variables and Data Types
- Practiced `var`, `let`, and `const`.
- Worked with strings, numbers, booleans, and arrays.
- Used `typeof` and `console.log()`.

### Assignment 2: Tip Calculator
- Took input from the user.
- Converted input into numbers.
- Calculated the tip and final bill amount.

### Assignment 3: Conditional Statements
- Practiced `if/else` statements.
- Used the `switch` statement.
- Worked with the ternary operator.

### Assignment 4: Loops
- Practiced `for`, `while`, and `do...while` loops.
- Used `continue` to skip certain iterations.

### Assignment 5: Functions and Scope
- Created regular and arrow functions.
- Worked with parameters and default values.
- Practiced block scope using `let`.

### Assignment 6: Array Methods
- Used `forEach()` to access array items.
- Used `filter()` to select products.
- Used `map()` to create a new array from existing data.

## Capstone Project: Product Inventory Dashboard

This is a simple web application made with HTML, CSS, and JavaScript. It helps users add products, view their prices, and calculate inventory values.

### Features
- Add and delete products.
- Display product names and prices.
- Categorize products as Budget, Standard, or Premium.
- Search for products by name.
- Filter products by price category.
- Calculate the total inventory value.
- Calculate tax and discount.
- Generate an inventory report.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- JavaScript Array Methods

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `capstone.html` in your browser to use the dashboard.
4. Try adding products, searching, filtering, and deleting products.
5. Open the assignment files to practice the concepts.

You can run the JavaScript files using Node.js or a browser console, depending on the code. Open `assignment2.html` in a browser to use the Tip Calculator.
